# Code of Conduct

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone participating in the **Tri-Model AI Orchestrator** project.

## Expected Behavior
- Be respectful, constructive, and empathetic in issues, discussions, and code reviews.
- Focus feedback on technical merit and user impact rather than individuals.
- Respect project maintainers' time and follow issue/PR templates.

## Unacceptable Behavior
- Harassment, discrimination, personal attacks, or derogatory language.
- Publishing private information (such as API keys, credentials, or personal contact details) without consent.
- Submitting malicious code, secret-harvesting behavior, or deceptive pull requests.

## Reporting
Report conduct concerns privately to **oabaiadze@gmail.com**.
